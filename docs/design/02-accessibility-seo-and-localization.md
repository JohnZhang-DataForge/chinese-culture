# Accessibility, Discoverability and Localization

**Status:** Proposed

## Accessibility baseline

Use semantic heading order, keyboard-accessible menus, visible focus, descriptive links, image alt text, adequate color contrast, accessible forms if added, captions/transcripts for media and reduced-motion support. Target WCAG 2.2 AA where practical.

## Readability

Write clear summaries up front; define jargon and cultural references. Do not require Chinese literacy to understand an English-language lesson.

## SEO and discoverability

Unique descriptive titles and page descriptions; canonical URLs; meaningful internal links; logical navigation and sitemap; search-friendly static pages; accurate dates, authorship and update metadata. Avoid keyword stuffing and fabricated ratings.

## Localization strategy

Launch English-first with correct Chinese terminology and a model that can support Simplified Chinese, Traditional Chinese and other languages later. Provide explicit language links only when reviewed translations exist.

## Translation process

Translate meaning and cultural context rather than word-for-word prose. Have a fluent reviewer check terminology, idioms and historical references. Preserve provenance and a review date; flag translations needing update when a source page changes.

## Chinese-language details

Display characters and Pinyin consistently, distinguish character variants when appropriate and ensure typefaces handle multilingual text. Test mixed-script line breaks and screen reader pronunciation.

## Date and calendar rules

Distinguish Gregorian event dates from traditional lunar calendar references. Do not assume that a festival occurs on the same Gregorian date each year; verify all practical event schedules with the organizer.

## Acceptance

Critical paths work with keyboard and screen reader, localized navigation does not lead to missing pages, and metadata accurately represents each article.
