# ADR-0003: English-first, Translation-ready Publication

**Status:** Proposed

## Context

The website wants to teach Chinese culture to international audiences. Translating all materials before launch could delay high-quality educational publication.

## Decision

Launch primarily in English, with culturally accurate Chinese terms and a localization-ready content model. Add fully reviewed additional-language pages incrementally.

## Consequences

English-speaking beginners can use the first release, while Mandarin-speaking reviewers can validate terms. Some audiences will lack full localization initially.

## Follow-up

Define language URL behavior, term glossaries, source-to-translation relationships and review ownership before implementing routes. Do not publish machine-generated translations as verified content without human review.

## Review trigger

Change this decision if the intended audience, reviewer capacity or launch partner requires a different primary language.
