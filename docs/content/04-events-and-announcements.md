# Events, Festivals and Announcements

**Status:** Proposed

## Distinguish two types of content

**Festival pages** are evergreen educational explanations. **Event announcements** describe a specific scheduled activity, date and organizer. The event may link to a festival reference but does not replace it.

## Required event metadata

Title; organizer; official source; date and time with timezone; physical location or online format; admission cost; accessibility notes if provided; attendance/registration URL; cancellation or sold-out status; verification date.

## Publishing workflow

1. Obtain organizer information from an official source.
2. Verify name, location, date/time and registration link.
3. Write a factual, concise event description with explicit organizer attribution.
4. Have an editor review potential privacy and image-rights concerns.
5. Publish with a future expiration rule and a clear status indicator.
6. Recheck near the event date; archive or mark expired afterward.

## Initial functionality

Curated list of upcoming events, event detail pages and a past-event archive. Filter by date or online/in-person only when needed. No native ticketing, payments or registrations for MVP.

## Anti-abuse safeguards

Do not accept anonymous self-publishing, unverified sponsorships or misleading links. If submissions are added later, require moderation, rate limiting and a takedown process.

## Example categories

Museum exhibitions, public festivals, library talks, beginner workshops, language/calligraphy sessions and virtual educational events.

## Acceptance

An event page tells users clearly whether it is upcoming, completed or canceled; all actionable links point to verified organizers.
