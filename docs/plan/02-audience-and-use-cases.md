# Audiences and User Journeys

**Status:** Proposed

## Primary audiences

- **Curious international readers:** want a clear explanation of a custom, object or celebration.
- **Students and beginners:** want a guided introduction with terms, examples and a next lesson.
- **Teachers and parents:** need trustworthy learning material and age-appropriate references.
- **Readers interested in Chinese literature:** want book context, reading order and legitimate sources.
- **Community members and event organizers:** want accurate dates and event information.

## Core user journeys

### Discover a tradition
A visitor arrives from a search about the Mid-Autumn Festival → reads a short answer → explores history, common customs and regional differences → follows links to another festival and a beginner lesson.

### Follow a learning path
A beginner opens Learn → selects Foundations → reads the lesson goal and key terms → completes a short self-check → moves to the next lesson. No account or saved progress is required initially.

### Find an event
A visitor opens Events → checks location, timezone, eligibility, cost and organizer → follows the official organizer link. Historical events are marked expired and are not shown as upcoming.

### Choose a book
A visitor opens Books → filters by topic or reading level → reads a summary, author context and edition/language guidance → follows a legitimate library, publisher or retailer link.

## Accessibility expectations

Visitors must be able to use the site on phones and with keyboard navigation. Chinese characters need accessible names and English explanations where appropriate. Do not rely on hover-only interactions, color alone or autoplay.

## Content expectations

Every educational page answers: What is this? Where/when is it relevant? What might vary? What should I read next? What sources support it?

## Success signals

Readers reach relevant pages, navigate to next lessons, and report that information was understandable and respectful.
