# Product Backlog and Dependencies

**Status:** Proposed

## Priority 0 — planning, before code

- **P0-01** Approve audiences, site promise and editorial boundaries.
- **P0-02** Approve MVP sitemap, categories and page specifications.
- **P0-03** Decide language rollout, translation ownership and terminology standards.
- **P0-04** Confirm publishing editors, reviewers and correction contact.
- **P0-05** Approve static hosting, cost ceiling and domain decision.
- **P0-06** Review copyright, privacy, source attribution and accessibility baseline.

## Priority 1 — foundations, future implementation

- **P1-01** Initialize Astro and site folders after ADR acceptance.
- **P1-02** Build accessible responsive shell and navigation.
- **P1-03** Define Markdown content metadata and validation.
- **P1-04** Build article, lesson, festival, book and event templates.
- **P1-05** Add automated build/link/metadata/accessibility checks.
- **P1-06** Enable secure preview and release processes.

## Priority 2 — content and launch

- **P2-01** Research and edit the initial cultural articles.
- **P2-02** Prepare the beginner curriculum and term glossary.
- **P2-03** Verify book editions, festival dates and real events.
- **P2-04** Produce licensed illustrations and image credits.
- **P2-05** Review with pilot readers, fix issues and launch.

## Deferred

On-site search enhancement, translations beyond capacity, newsletter, event submissions, registration, user accounts, learning progress and OpenAPI services.

## Issue-ready acceptance template

Each work item includes problem, reader benefit, scope, dependencies, owner, acceptance criteria, validation method, cost/privacy impact and documentation links.

## Delivery rule

Close planning tasks only when documented decisions are accepted. Do not mark a feature completed without demonstrable tests and release evidence.
