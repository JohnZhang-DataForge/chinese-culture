# Sitemap and Navigation

**Status:** Proposed

## Proposed site map

- **Home** — mission, start learning, featured stories, upcoming events.
- **Learn**
  - Beginner paths
  - Course overview
  - Individual lesson
- **Explore Culture**
  - Traditions and daily life
  - Arts and crafts
  - History and heritage
  - Philosophy and ideas
  - Food and tea
  - Article detail
- **Festivals**
  - Festival index
  - Festival detail
- **Books**
  - Book guide index
  - Book guide detail
- **Events**
  - Upcoming event list
  - Event detail
  - Past event archive
- **About**
  - Mission and team
  - Editorial principles
  - Contact
- **Policies**
  - Privacy
  - Copyright and attribution
  - Accessibility

## Header

Home | Learn | Culture | Festivals | Books | Events | About. On narrow screens provide an accessible menu with visible focus and clear labels.

## Footer

About, Contact, Editorial Policy, Privacy, Copyright/Attribution, Accessibility; optionally a link to the project's published changelog.

## Navigation behavior

- Use page breadcrumbs on deeper pages.
- Learning paths include previous/next lesson controls.
- Topic pages link to related lessons, festival pages and books.
- Expired events stay linkable but clearly indicate that they have ended.
- Handle not-found pages with a helpful route back to major sections.

## Acceptance

One canonical URL per content item; no dead-end article; no misleading navigation placeholders; mobile menu and keyboard navigation fully usable.
